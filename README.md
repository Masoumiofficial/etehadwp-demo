# نمایشگاه دموهای طراحی سایت اتحاد وردپرس (demo.etehadwp.com)

این مخزن شامل صفحه اصلی نمایشگاه زنده دموهای **اتحاد وردپرس** و پیش‌نمایشگر تعاملی (`/preview/`) است.

## ساختار پروژه

- `index.html` — صفحه فرود اصلی نمایشگاه دموها (`/`)
- `preview/index.html` — محیط پیش‌نمایش زنده دموها در نمای دسکتاپ، تبلت و موبایل (`/preview/`)
- `assets/js/demos-config.js` و `data/demos.json` — رجیستری مرکزی دموها و دسته‌بندی‌ها برای افزودن آسان دموهای جدید
- `assets/js/main.js` — منطق جستجوی زنده، فیلتر دسته‌بندی‌ها، تغییر نمای نمایشگر هیرو و منوی موبایل
- `assets/js/preview.js` — منطق انتخاب دمو، تغییر دستگاه، بارگذاری مجدد و نمایش امکانات دمو
- `assets/css/tokens.css`, `assets/css/main.css`, `assets/css/preview.css` — توکن‌های طراحی، استایل صفحه اصلی و پیش‌نمایشگر
- `assets/fonts/Vazirmatn-Variable.woff2` — فونت میزبانی‌شده محلی برای سرعت و پایداری بارگذاری
- `assets/images/demos/` — تصاویر پشتیبان اختصاصی برای هر دمو
- `robots.txt` و `sitemap.xml` — تنظیمات ایندکس‌پذیری و نقشه سایت

## افزودن دموی جدید

برای اضافه کردن دموی تازه بدون تغییر در ساختار صفحه، کافی است یک آبجکت جدید به آرایه `demos` در `assets/js/demos-config.js` (و `data/demos.json`) اضافه کنید.

## حفظ مسیرهای مستقل وردپرس

مسیرهای `/digital/`، `/fashion/`، `/beauty/` و `/beauty-plus/` به عنوان نصب‌های مستقل وردپرس دست‌نخورده باقی می‌مانند و فایل‌های این پروژه بدون تداخل با آن‌ها در ریشه دامنه سرو می‌شوند.
